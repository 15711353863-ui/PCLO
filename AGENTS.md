# Plain Craft Launcher Open project instructions

- Work locally by default. Push to GitHub, upload assets, create releases, or otherwise publish only after the human user explicitly says to upload/publish the current work. Past upload permission does not authorize later revisions.
- The product name is Plain Craft Launcher Open. Use PCLO only when an abbreviation is appropriate. The active icon is derived from the original blue hexagonal PCL badge, with PCL above OPEN.
- Preserve the original PCL interface and visual language. Network requests must not contact the original author's service hosts; use project official sources and domestic public mirrors concurrently, with failover and file verification.
- Preserve upstream licensing and attribution. MIT applies only to the independently authored files listed in LICENSING.md.
- Build local Windows previews with BUILD-PREVIEW.ps1. Generate icon sizes and ICO from assets/pclo-source.png with BUILD-ICON.ps1.
